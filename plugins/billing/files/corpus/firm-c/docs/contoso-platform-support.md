# Working With Platform Support

## When to Contact Support

Contoso Advisors contacts TAMP platform support when a billing problem cannot be solved with the firm's own procedures. Typical reasons are a run that stays in running status for more than two hours, an unfamiliar failure code, a custodian fee file that the platform cannot generate, or a calculation that appears to contradict the configured schedule. Routine failures such as FS-REQUIRED or AUM-STALE are handled internally and do not need a support ticket.

## Opening a Ticket

### Information to Include

The ticket includes the run identifier, the billing period, the status shown on the platform, the failure reason text if any, and the number of affected accounts. Account numbers are not included in the ticket body; support can look them up from the run identifier. Screenshots must have client names redacted.

### Who Opens Tickets

Only the operations lead opens tickets, so that support receives one consistent contact from Contoso Advisors. The associate prepares the ticket details and the lead submits them.

## Follow-Up

The operations lead records the ticket number in the exception log and checks on it daily until resolved. If support asks the firm to re-run a billing run, the associate performs the re-run and records the new run identifier alongside the old one. Resolution notes are added to the quarterly billing binder.
