# Contoso Advisors Billing Calendar 2026

## Quarterly Runs

The 2026 billing calendar sets the start dates for each quarterly-in-advance run at Contoso Advisors. The Q1 run starts on January 2, the Q2 run on April 1, the Q3 run on July 1, and the Q4 run on October 1. Each run uses the valuation from the last business day of the previous quarter. The operations associate starts the run in the morning, and the operations lead reviews and approves invoices by the end of the second business day. The custodian fee file is submitted on approval.

## Preparation Deadlines

### Five Business Days Before

New households signed during the quarter must be fully linked, and all accounts must have a fee schedule assigned. The associate runs the unassigned-accounts report and clears it so the run does not fail with FS-REQUIRED.

### Two Business Days Before

Household rebalancing fee adjustments and approved waivers must be entered. Termination effective dates must be recorded so the platform can calculate refunds for the prior quarter.

## Closing the Period

After fees are reconciled with the custodian, the operations lead closes the billing period on the platform. Once closed, the period cannot receive new adjustments; any later correction is booked in the next open period as a credit or debit. The target is to close each period within fifteen business days of the run start date.
