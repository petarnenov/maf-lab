# Performance Reporting

## Time-Weighted and Money-Weighted Returns

The platform reports two kinds of return. Time-weighted return (TWR) measures how the investments performed, independent of when the client added or removed money. It breaks the period at every external cash flow, measures each sub-period, and links the results, so it is the correct measure for judging a model portfolio or a manager. Money-weighted return, calculated as an internal rate of return, reflects the size and timing of the client's own flows and answers the question "how did my money do?" The two can differ materially when a large contribution arrives just before a market decline or rally.

## Gross-of-Fee and Net-of-Fee Returns

Gross-of-fee return is the return of the portfolio before advisory fees. Net-of-fee return deducts the advisory fees charged to the account during the period. When the billing engine debits a fee from the account, that debit reduces the account's market value but is not treated as an external withdrawal for net-of-fee purposes; it is treated as a cost, so it lowers net return. For gross-of-fee reporting, the same debit is treated as a flow and excluded. Fees paid from outside the account, such as by check or from another account, affect only the paying account. Reports always state which basis is shown.

## Benchmark Comparison

Each model portfolio is paired with a blended benchmark built from index returns in the same proportions as the model's target weights, for example a 60/40 blend of a broad equity index and an aggregate bond index for a balanced model. Account returns are compared with the benchmark over the same period on a TWR basis. Differences arise from drift (the account did not hold exactly the target weights), security selection within each asset class, cash drag and fees. The attribution section of the report separates allocation effect, which comes from drift, from selection effect.

## Reporting Periods

Standard periods are month-to-date, quarter-to-date, year-to-date, trailing one, three and five years, and since inception. Periods longer than one year are annualized. Quarterly client reports use the official quarter-end valuation as the ending value, so the ending market value on the performance report matches the value used for billing and for the quarter-end drift report. An account needs a full month of history before monthly returns are shown and a full quarter before it appears in composite reporting.

## Common Reconciliation Questions

Clients sometimes ask why their account value rose while their return was negative; the answer is almost always a contribution, which raises value but is excluded from TWR. The reverse, a positive return with a lower value, usually points to a withdrawal. Differences between gross and net return over a quarter should approximate the quarterly fee rate.
