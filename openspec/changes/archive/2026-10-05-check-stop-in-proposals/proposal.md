# Proposal

## Why

`stop-anything` says every proposal that adds or changes work a person can start must say how it is stopped and how
a stop is shown — but only review enforces it, so a proposal can forget it and nothing fails. The rule is a
first-class one in this project; it should fail the build the way a missing `Documentation impact` section already
does.

## What Changes

- `make docs-check` checks every active change's `proposal.md` for a `## Stopping` section, and fails, naming the
  change and the reason, when the section is missing or empty, or says neither of the two things it may say:
  - **None:** a line starting `None — ` (or `None:`) followed by a reason: the change adds or changes nothing a
    person can start;
  - **The four facts:** one non-empty line each for `Key:` (how a person stops it — Esc on the page, Ctrl+C or SIGTERM
    in a terminal), `Stop:` (the protocol's own stop or this system's cancel route that carries it), `Recorded in:`
    (the store that records the stop, or `the request itself` for work that lives inside one request) and `Shown:`
    (how the page or the terminal says it is stopping and then stopped).
- `openspec/config.yaml`'s proposal rules tell every proposal author to write the section, so the OpenSpec
  instructions say it before the check has to.
- What the section says is not judged: whether `Key: Esc` is the right key is still review's call. The check makes
  sure it was said.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `documentation-sync`: "The documentation check" adds the `## Stopping` rule beside the `Documentation impact` one.
- `stop-anything`: "Changes are checked against the rule" — the section is how a proposal says it, and
  `make docs-check` fails a proposal that does not.

## Impact

- `scripts/docs.py` (`check_change_proposals`), `scripts/tests/test_docs.py`, `openspec/config.yaml` (`rules.proposal`).
- No product code, no route, no target. `make docs-check` already runs in CI (`make ci`); it simply has one more rule.
- Active changes: none today, so nothing in the tree has to be rewritten.

## Stopping

None — this change adds no work a person can start: it adds a rule to a check that runs and ends in moments.

## Documentation impact

- `CLAUDE.md`: the stop-anything non-negotiable says `make docs-check` enforces the `## Stopping` section.
- `openspec/project.md`: the "Everything can be stopped" convention says the same (its copy in `openspec/config.yaml`
  is regenerated by `make docs`).
- `.github/copilot-instructions.md`: the same sentence in its stop rule.
