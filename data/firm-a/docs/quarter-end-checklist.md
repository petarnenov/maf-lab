# Quarter-End Billing Checklist for Acme Wealth Partners

## Before the Run

OPS confirms that custodian feeds have loaded for every business day in the quarter, that the stale-valuation report is empty, and that all new accounts opened during the quarter have ACME-TIER-2026 or an approved exception assigned. Advisors confirm their billing previews and report any pending credits. Household splits and merges requested before quarter end must be completed before the run.

## During the Run

### Monitoring

OPS watches the run status. A run that stays in running status for more than two hours is escalated to platform support. A failed run is triaged immediately using the failure code, and the billing desk is notified.

### Approvals

FIRM_ADMIN users clear the approval queue for invoices over $25,000 within two business days of the run completing.

## After the Run

Fee files are submitted, custodian deductions are reconciled, CUSTODIAN-MISMATCH exceptions are resolved, and the period is closed. The billing desk files the run report and the approval log in the operations archive.
